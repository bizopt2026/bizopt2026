# 솔루션 박스 디자인 컨셉: 차분한 작업대

솔루션 박스는 매일 여는 사내 업무 도구다. 화려할 필요는 없고, 열었을 때 **오늘 할 일과 지금 단계가 바로 보이고, 실수로 지울 일이 없어야** 한다. 그래서 컨셉은 "잘 정돈된 작업대"다. 바탕은 조용하고, 색은 의미가 있을 때만 쓰고, 일의 흐름(발굴 단계, 제안 단계)이 눈에 보이게 한다.

## 다섯 가지 원칙

1. **색은 의미에만 쓴다.** 바탕과 글은 무채색이다. 색은 강조색 한 가지(남색)와 상태색(진행·주의·위험·완료), AI 표시색(보라)만 쓴다. 장식용 색은 쓰지 않는다.
2. **한 화면에 주 행동은 하나다.** 꽉 찬 남색 버튼(주 버튼)은 화면마다 한 개만 둔다. 나머지는 흰 바탕 보조 버튼, 지우기는 빨간 테두리 위험 버튼이다. 위험 버튼은 항상 주 버튼에서 멀리, 오른쪽 끝이나 맨 아래에 둔다.
3. **흐름을 보여 준다.** 솔루션 발굴 단계와 제안 단계는 진행 막대(스텝)로 보여 준다. 지난 단계, 지금 단계, 아직 못 하는 단계가 모양으로 구분된다.
4. **AI 결과는 초안이라는 표시를 단다.** AI가 만든 내용과 AI 작업 상태에는 보라색 "AI" 표식을 붙인다. 사람이 저장하기 전까지는 초안이라는 앱 규칙이 화면에서도 보이게 한다.
5. **휴대폰에서도 기록할 수 있다.** 미팅 직후 휴대폰으로 메모를 남길 수 있어야 한다. 좁은 화면에서는 메뉴가 가로로 밀리고, 표는 카드처럼 한 줄씩 쌓인다.

## 디자인 토큰 (`app/static/app.css` 의 `:root`)

| 쓰임 | 토큰 | 값 |
|---|---|---|
| 글 | `--fg` / `--muted` | `#1b2230` / `#5f6b7d` |
| 바탕 / 면 | `--bg` / `--surface` | `#f4f5f8` / `#ffffff` |
| 선 | `--line` / `--line-strong` | `#dfe3ea` / `#c5ccd8` |
| 강조(주 버튼·링크·현재 위치) | `--accent` / `--accent-soft` | `#2f47c9` / `#eef1fd` |
| AI 표시 | `--ai` / `--ai-soft` | `#6b4fd1` / `#f3f0fd` |
| 완료 | `--ok` / `--ok-soft` | `#17794a` / `#e8f6ee` |
| 주의(기한 임박·확인 필요) | `--warn` / `--warn-soft` | `#a15c00` / `#fff4e0` |
| 위험(오류·삭제·기한 지남) | `--err` / `--err-soft` | `#b42318` / `#fdeeec` |

- **글꼴**: 설치된 글꼴만 쓴다(사내망에서 외부 글꼴을 받지 않는다). Pretendard가 있으면 쓰고, 없으면 맑은 고딕, Apple SD Gothic Neo, Noto Sans KR 순서다. 본문 15px, 표 안 숫자는 고정폭 숫자(`tabular-nums`)다.
- **간격**: 4의 배수(4·8·12·16·24)로 맞춘다. 카드 안쪽 여백은 20px, 카드 사이는 16px이다.
- **모서리**: 버튼과 입력칸 6px, 카드 10px, 배지 999px(알약 모양)이다.
- **초점**: 키보드로 이동하면 강조색 2px 바깥 테두리를 보여 준다.

## 발굴 단계 색

| 단계 | 색 | 뜻 |
|---|---|---|
| 아이템 접수 | 회색 | 막 들어온 것 |
| 사전 태핑 | 하늘색 | 고객 반응 확인 중 |
| 수요조사 | 주황 | 수요 검증 중 |
| 박스 등록 | 초록 | 제안에 쓸 수 있음 |
| 보류 | 연회색 점선 | 흐름 밖 |

## 구성 요소

- **화면 머리**: 이동 경로(예: 솔루션 › 이름), 제목, 오른쪽 끝에 수정·삭제 버튼을 둔다.
- **버튼**: 주(`.primary`), 보조(기본), 위험(`.danger`), 작은 버튼(`.small`)이 있다. 버튼처럼 보이는 링크는 `a.btn`이다.
- **알림 띠**: 정보(`.notice`), 저장 확인(`.flash`, 저장 뒤 한 번 표시), 오류(`.error`), AI 진행(`.ai-banner`)을 구분한다.
- **스텝**: `.stepper`. 발굴 단계와 제안 단계에 쓴다.
- **배지·칩**: 상태는 배지, 태그는 눌러서 거를 수 있는 칩이다.
- **빈 값**: 상세 화면에서 비어 있는 값은 "—"로 보여 준다.
- **표**: 머리를 누르면 정렬된다(`table.sortable`). 좁은 화면에서는 줄마다 카드처럼 쌓인다.
- **파일 선택**: 한국어 "파일 선택" 버튼과 고른 파일 이름을 보여 준다.

## 하지 않는 것

- 외부 CDN 글꼴·아이콘·스크립트를 쓰지 않는다. 서버 PC가 사내망에 있다.
- 그림자, 그라데이션, 애니메이션을 장식으로 쓰지 않는다. 움직임은 AI 진행 표시 하나뿐이다.
- 화면 문구를 영어로 두지 않는다.
